# Paired replay of the original dated records

Rubén Abella · SPE Audit · research edition 1.2 · 22 November 2026

This is a retrospective analysis of all 112 published English classification rows at revision c6126e42bc8cd0679ac3c5f5dca6270c0a1ccc6f. The primary 96 and the 16 wording challenges concern the same four space missions. Their rules, labels and aggregate results were already public when this protocol was written. Twelve deterministic source-selection checks are excluded. No new event, annotation or response from a public AI service is being sampled.

One frozen local reader (SmolLM2-135M-Instruct Q4_K_M, llama.cpp b8058) classifies each existing answer twice. Both inputs contain the same cutoff, question, answer, and only the date and text of each eligible source card in its captured order. We strip URLs and descriptive card identifiers. The retrospective arm adds exactly one field with the registered event date, even when that date lies beyond the cutoff. The other arm omits this field. A card, the answer, the question or the model's prior training may still reveal timing. Withholding the field is not evidence that a pretrained model is blind to the event. Neither arm receives reference labels or method predictions.

Each call is a separate completion without chat history. The two arms alternate their starting order by row number. The prompt, model, grammar, temperature 0, seed 20261122 and input ordering are fixed before this particular inference. No tuning or selection of runs on the labels. We intend one inference per arm per row, with no retries or replacement of invalid decisions. Runtime errors stay distinct and count towards workload if a human must take over. A second run, if attempted, must be described separately.

After recording the two outputs, join them to the published year rule, date-aware matcher and editorial reference by case identifier. Report positive alerts/all reference positives, false alerts/all controls, REVIEW/all rows, automatic decisions/all rows, correct/automatic, alert precision, and failures by split and method. Report paired decision changes and their direction, including changes that trade a true or false decision for abstention. Results are descriptive within this model, prompt, grammar and selected rows. No population interval or inference over independently sampled events is planned. A cryptographic commitment can identify the frozen inputs and code. It cannot turn this previously public corpus into a prospective holdout.
