# Exploratory semantic reading · Lectura semántica exploratoria

This additional comparator was commissioned after the 1.1 rule’s aggregate results had been seen. The new challenge labels and source files were already fixed. The independent reading instance was given only a shuffled masked worksheet and the following instructions. It was not shown reference labels, rule predictions, their metrics or calibration. This is one AI-assisted reading, not human annotation, a production API deployment, or a reproducible fresh model invocation. The release can reproduce the worksheet and score the archived answers. Model version, sampling parameters and provider-side processing are not attested.

**Instructions to reader:** For the nominated event and inclusive reporting cutoff, classify what the supplied answer itself communicates about the event. A speaker’s commitment that the event happened, including an unambiguous presupposition, counts as POST_ASSERTION when the verified event date is after cutoff. A plan, hypothetical, unendorsed quotation, open question or denial alone does not assert completion. For a past event or clear absence of a post-cutoff assertion use OTHER. When reference, scope, speaker commitment or same-day precision prevents a defensible determination use REVIEW. Split mixed claims and evaluate the strongest clearly attributable completed outcome. Use the question only to interpret referents, not as evidence that its claims are endorsed by the answer. Provide one label and a short rationale per item. No external research. The date of the event is given to the evaluator for retrospective comparison; its presence does not mean the producer of the original answer received it.

**Interpretation.** A discrepancy from a single author’s reference can reveal an error or a genuine disagreement. The decisions are not calibrated probabilities. The reader is an AI instance in the same project platform. Its run is not externally signed. Human validity, reviewer time and causal attribution remain distinct outcomes.
